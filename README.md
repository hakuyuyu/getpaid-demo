# GetPaid — interactive demo

**by Haku**

This is the free interactive demo for **GetPaid** ($39 one-time), the overdue-invoice reminder tool for freelancers.

Open `index.html` in a browser to walk through the flow: scan sent invoices → find the overdue ones → preview the three-stage reminder drafts (polite nudge → firm reminder → final notice).

GetPaid only ever creates **drafts** — it cannot send email. You read every word before it goes out.
